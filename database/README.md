# FleetHealth Database

## Database: MySQL 8

### Setup

```sql
CREATE DATABASE IF NOT EXISTS fleethealth;
```

Spring Data JPA auto-creates tables via `spring.jpa.hibernate.ddl-auto=update`.

### Tables

1. **vehicle** — stores vehicle information
2. **vehicle_health** — stores health telemetry readings
3. **maintenance_alert** — stores maintenance alerts generated by the rule engine

### Connection

- Host: `localhost`
- Port: `3306`
- Database: `fleethealth`
- Username: `root`
